# 实施顺序

1. **合同确认**：确定 API、数据库、鉴权、文件、支付和权限合同；把 D02 Token 别名统一为 `colors.*`、`typography.*`。
2. **基础壳层**：接入三端路由、主题 Token、注册 SVG 图标、状态反馈组件和返回恢复存储。
3. **最小业务闭环**：登录/注册 → 实名认证 → 发布入口 → 发布编辑 → 预览提交 → 审核结果。
4. **平台业务**：内容、搜索、订单/支付、钱包/提现、消息、申诉和管理后台治理。
5. **证据验收**：服务器构建与测试；连接真实 Android 设备后逐页截图、日志检查和视觉差异验收。

第一阶段不复制 1,153 份大型 HTML/PNG 到代码仓库，避免仓库膨胀；设计包通过版本化来源或制品存储关联。
