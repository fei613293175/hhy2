## 必须补齐的接口合同

| 领域 | 当前只有 | 开发前必须确定 |
|---|---|---|
| 鉴权 | `auth` 分组和会话描述 | URL、方法、Token/刷新、过期、注销、错误码 |
| 发布 | `publish` 分组和页面状态 | 草稿幂等键、字段校验、上传协议、审核回调、回滚 |
| 支付 | 页面与状态 | 订单生命周期、金额精度、回调验签、退款规则 |
| 数据 | 表名 | 字段、关系、索引、租户隔离、审计字段 |
| 权限 | 页面角色文字 | 可执行 RBAC/ABAC 权限矩阵和服务端强校验 |
| 分析 | 少量或空埋点声明 | 事件名、属性 schema、采样、隐私和失败重试 |

## 构建与验收边界

按 `AGENTS.md`，本机不安装依赖、不构建、不启动项目。服务器构建入口、环境变量和签名配置确认后，才进入三端工程实现。真机验收必须安装并启动 APK，逐页执行真实点击、输入、返回、滚动和关键流程，并保留截图、日志和设备信息。
